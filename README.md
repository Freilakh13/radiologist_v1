## 📖 О проекте

**Radiologist** — это интерактивный тренажёр для студентов медицинских 
университетов, который помогает отработать навыки описания медицинских 
изображений на реальных клинических случаях.

Проект создан командой молодых разработчиков из РТУ МИРЭА и уже прошёл 
апробацию в Первом МГМУ им. И.М. Сеченова.

## ✨ Возможности

### 🎓 Для студента

- **14 ситуативных кейсов** — реальные клинические случаи для практики
- **Алгоритм проверки** развёрнутого описания снимков
- **Обратная связь** по каждому ответу
- **Личный кабинет** с сохранением результатов

### 👨‍🏫 Для преподавателя

- **Мониторинг успеваемости** студентов в реальном времени
- **Автоматический рейтинг** — формируется без ручной работы

### 👤 Гостевой режим

Можно пройти кейсы как студент, но **без сохранения результатов** — 
после закрытия окна прогресс сбрасывается.
