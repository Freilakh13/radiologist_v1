## 📖 О проекте

**Radiologist** — это интерактивный тренажёр для студентов медицинских 
университетов, который помогает отработать навыки описания медицинских 
изображений на реальных клинических случаях.

Проект создан командой молодых разработчиков из РТУ МИРЭА и уже прошёл 
апробацию в Первом МГМУ им. И.М. Сеченова.

> 🌐 **Веб-версия** — работает на любой ОС (Windows, macOS, Linux), 
> достаточно браузера. Нужна **внешняя клавиатура**: тренажёр предполагает 
> ввод развёрнутых описаний снимков, а виртуальной клавиатуры в нём нет.
>
> 💻 **Windows-версия** — полный функционал с сохранением результатов. 
> **Работает без интернета**: все данные хранятся локально, 
> можно вести до **5 пользователей** на одном устройстве.

> ⚠️ **Важно:** мониторинг успеваемости преподавателем и автоматический 
> рейтинг работают **только в веб-версии**. В офлайн-режиме преподаватель 
> не сможет отслеживать прогресс студентов — для этого нужно подключение 
> к интернету.
### 🔌 Главная особенность

Наш тренажёр **не требует постоянного подключения к интернету**. 
Алгоритм проверки описаний работает полностью офлайн — это важно 
для медицинских учреждений с нестабильной связью или закрытым контуром.

## ✨ Возможности

### 🎓 Для студента

- **14 ситуативных кейсов** — реальные клинические случаи для практики
- **Алгоритм проверки** развёрнутого описания снимков
- **Обратная связь** по каждому ответу
- **Личный кабинет** с сохранением результатов

### 👨‍🏫 Для преподавателя

- **Мониторинг успеваемости** студентов в реальном времени
- **Автоматический рейтинг** — формируется без ручной работы

### 👤 Гостевой режим

Можно пройти кейсы как студент, но **без сохранения результатов** — 
после закрытия окна прогресс сбрасывается.
